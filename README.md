# EvokerAug

EvokerAug is a Retail Midnight 12.x helper for Augmentation Evokers who want a compact party-buff tracker and click-cast frame for allies.

## Key Features

- Shows selected party members as class-coloured frames for quick buff targeting.
- Tracks Prescience with a shrinking row fill so refresh timing is visible at a glance.
- Adds a separate movable Prescience Thin Tracker with small DPS-only bars for clean Mythic+ refresh timing.
- Shows a small range marker on each Thin Tracker row so nearby and distant DPS are easy to tell apart.
- Highlights Thin Tracker rows when a tracked DPS offensive burst window is active.
- Includes a Thin Tracker test mode in settings so the bars can be previewed and tuned without a party.
- Shows active tracked buff icons, including Prescience and other Augmentation support buffs.
- Supports favorites, auto-fill, frame sorting, icon sizing, and an optional Ebon Might progress bar.
- Opens settings with `/aug`, the minimap/compartment button, or the frame controls.

## Installation and Usage

Install EvokerAug in `Interface\AddOns\EvokerAug`, then type `/aug` in game to open settings. Right-click the EvokerAug frame to select party members, unlock or lock the frame, auto-fill Mythic+ party members, or clear the current frames.

Selected party rows can be clicked to cast the configured spells through the addon secure buttons. Because WoW protects click-cast frame changes during combat, roster and settings changes may queue until combat ends.
